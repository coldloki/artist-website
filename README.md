# Antónia de Távora — Santhiago Collection

A modern static portfolio site for the painter [Antónia Camilo de Távora](https://fortytwo.net/antonia/), built around her *Santhiago Collection* — 15 oil paintings made in Cascais and Sintra, Portugal, between 2000 and 2004.

Local-only proposal build. Originally designed as a replacement for her existing very old site.

## Run locally with Docker

```sh
docker compose up -d --build
# open http://localhost:8080
```

The first build takes a few seconds (downloading the nginx base image). Subsequent rebuilds are near-instant.

## Build the static site

The site is generated from the canonical catalog by `build.py`. After editing `_meta/santhiago.json` (titles, dimensions, image references, etc.):

```sh
python build.py
docker compose restart web
```

The build script reads the catalog, applies responsive `<picture>` markup with WebP variants, and emits 19 HTML files into `public/`.

## Project structure

```
.
├── build.py                  # generates all HTML from the catalog
├── Dockerfile                # nginx:1.27-alpine + custom config
├── docker-compose.yml        # exposes port 8080
├── README.md                 # this file
├── .gitignore                # excludes generated public/ and cache files
│
├── assets/                   # original artwork JPEGs (and WebP variants)
│   ├── Antonia Portrait.jpg
│   ├── _MAG0002.jpg ... _MAG9982.jpg
│   └── _MAG*.webp            # generated by build pipeline (committed for static deploys)
│
├── public/                   # generated HTML + static CSS/JS
│   ├── index.html
│   ├── portraits.html / natures-mortes.html / paisagens.html
│   ├── assets/style.css, app.js
│   └── paintings/<cat>/<slug>.html  # one detail page per painting
│
└── _meta/                    # canonical catalog (source of truth)
    └── santhiago.json
```

## Adding a new painting

1. Drop the JPEG in `assets/` (any name is fine; the catalog file is the source of truth)
2. Add a row to `_meta/santhiago.json` with `title`, `dimensions` (e.g. `"50/70 cm"`), `medium`, `image_file`, `category`, `slug`
3. Run `python build.py` to regenerate HTML

## Performance

- **First-page payload on mobile:** ~225 KB (HTML + CSS + JS + 4 small WebP thumbnails)
- **Images:** WebP variants automatically generated; full-size and ≤480px thumbnail per file
- **Critical CSS:** inlined for first paint; full stylesheet loads asynchronously
- **Caching:** HTML=5min, CSS/JS=7d (version-busted via `?v=` query), images=7d `immutable`

## Stack

- **Static HTML + CSS + vanilla JS** — no build pipeline beyond `build.py` (Python stdlib only)
- **nginx 1.27-alpine** for serving
- **Cormorant Garamond** (display serif) + **Inter** (UI sans) from Google Fonts
- **Docker** for portable local hosting
